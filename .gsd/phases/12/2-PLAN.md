# Plan 12.2 - Operator PWA scaffold: installable, offline app shell

Working plan (brief). Source: REQ-120; BLUEPRINT section 12 "Client technology"; ADR-78.
Owns `apps/operator-pwa` (new workspace), root `package.json`, CI. Wave A, parallel with Plan 12.1.

## Tasks

1. **Workspace** - React 19 + TypeScript + Vite 8 + Tailwind 4, `@vo/operator-pwa`, dev/preview port 5210, `/api` proxy
   (default 8080, `VITE_API_ORIGIN` override). Root workspaces already glob `apps/*`; add CI lines (build + the PWA e2e).
2. **PWA shell** - `vite-plugin-pwa` (workbox `generateSW`, precache the app shell, `navigateFallback`, never cache
   `/api`), web app manifest (standalone, theme, 192/512 + maskable icons generated by `scripts/make-icons.mjs` from
   code: no external assets), update prompt.
3. **App frame** - router, i18n (`messages.en.ts`), connectivity banner (online/offline), sync badge, truth label,
   44px touch targets, WCAG 2.2 AA tokens, skip link, focus styles.

One commit per task.
